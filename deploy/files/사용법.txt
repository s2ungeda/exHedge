====================================================================
 TrdBot 배포판 사용법  (파이썬 설치 불필요)
====================================================================

이 폴더(TrdBot)를 통째로 원하는 위치에 복사해서 씁니다.
※ "Program Files" 같은 쓰기 제한 폴더는 피하세요. 토큰/로그를
   폴더 안에 파일로 남기므로, 문서 폴더나 D:\TrdBot 같은 곳을 권장합니다.


폴더 구성
--------------------------------------------------------------------
  TrdBot.exe    ← 봇 본체 (더블클릭해서 실행)
  setup.exe     ← 최초 1회, API 키·계좌비밀번호 등록용
  .env          ← 계좌번호 등 설정 (메모장으로 편집)
  _internal\    ← 실행에 필요한 파일들 (건드리지 마세요)

  실행하면 자동으로 생기는 것:
  tokens\       ← 발급받은 접속 토큰 캐시 (비밀값)
  logs\         ← 실행 로그 (logs\trdbot.log, 자정마다 날짜별 보관)
  config\       ← 화면 입력값 저장


====================================================================
 처음 설정 (최초 1회) — 키값·계좌번호·계좌비밀번호 입력
====================================================================

[1단계] API 키 + 계좌 비밀번호 등록  →  setup.exe 실행

  setup.exe 를 더블클릭(또는 명령창에서 실행).
  검은 창이 뜨면 순서대로 입력합니다 (입력값은 화면에 안 보입니다):

     주식 app_key    : (주식계좌 API 키)
     주식 app_secret : (주식계좌 API 시크릿)
     주식 계좌 비밀번호(4자리) :
     선물 app_key    : (선물계좌 API 키)
     선물 app_secret : (선물계좌 API 시크릿)
     선물 계좌 비밀번호(4자리) :

  - LS는 API 키를 계좌(주식/선물) 단위로 발급합니다. 선물만 쓰면
    선물 항목만 채우고 주식 항목은 빈 채로 엔터 쳐도 됩니다.
  - 빈 채로 엔터 = 기존 값 유지.
  - 입력한 키/비밀번호는 Windows 자격 증명 관리자에 암호화 저장됩니다
    (같은 Windows 사용자만 복호화 가능. 이 파일이나 폴더엔 안 남습니다).

  ※ 실거래 계좌로 설정하려면 명령창에서:  setup.exe --env prod
     (기본은 모의투자 mock)

[2단계] 계좌번호 입력  →  .env 파일 편집

  .env 파일을 메모장으로 열어 계좌번호를 채웁니다:

     LS_FUTURES_ACCOUNT_NO=여기에_선물계좌번호

  - 실거래로 쓰려면 LS_ENV=mock 을 LS_ENV=prod 로 바꿉니다.
    (setup.exe도 --env prod 로 등록했어야 함 — 환경이 서로 맞아야 함)

[확인] 제대로 등록됐는지 보려면 명령창에서:
     setup.exe --check            (mock 확인)
     setup.exe --check --env prod (prod 확인)


====================================================================
 실행
====================================================================

  TrdBot.exe 더블클릭 → 자동주문화면이 뜹니다.

  - 로그는 화면(상단)과 logs\trdbot.log 파일에 함께 남습니다.
    밤새 돌린 뒤 아침에 logs 폴더에서 그날 로그를 확인할 수 있습니다.
  - 문제가 생기면 logs\trdbot.log 를 확인하세요.


====================================================================
 실거래(운영) 전환  ★ 실제 돈이 나가므로 신중히
====================================================================

모의투자(mock)에서 실매매(prod)로 바꾸려면 아래 3가지를 반드시
모두 바꿔야 합니다. 하나라도 빠지면 접속 실패하거나 엉뚱한
계좌로 붙습니다.

[바꿔야 할 것 3가지]

  ① .env 에서 환경을 prod 로
       LS_ENV=mock   →   LS_ENV=prod
     (이 한 줄이 실시간 포트·토큰·키 조회를 모두 실거래용으로 전환)

  ② .env 에서 계좌번호를 실거래 계좌로
       LS_FUTURES_ACCOUNT_NO=(실거래 선물 계좌번호)
     ※ 함정: 계좌번호는 환경별로 안 나뉩니다. LS_ENV만 prod로
        바꾸고 계좌번호를 모의 것 그대로 두면 안 됩니다.
        반드시 실거래 계좌번호로 함께 교체하세요.

  ③ setup.exe 로 실거래 키·계좌비번 등록 (명령창에서)
       setup.exe --env prod
     LS는 실거래용 API 키를 모의와 별도로 발급합니다.
     실거래 app_key/app_secret/계좌비밀번호를 새로 등록하세요.
     (모의 키로는 실거래 접속 불가)
     확인:  setup.exe --check --env prod

[실매매 전 점검]

  - TRDBOT_TEST_NOFILL_TICKS 환경변수가 시스템에 남아있지 않은지
    확인. (이건 테스트용 — 주문가를 체결 안 되는 방향으로 옮김.
     실매매에선 절대 켜지면 안 됨. 보통은 설정 안 하면 꺼짐)
  - 처음 실행은 항상 '주문' 체크 꺼진 관찰모드로 시작됩니다.
    몇 사이클 로그로 판단을 확인한 뒤 '주문'을 체크하세요.
  - 최대잔고한도 / 1회주문계약수를 실매매 규모로 다시 확인.
  - 상단 장운영 칩에 '실거래' 세션·접속매매가 뜨는지 확인.
  - LS에서 실거래용 API 사용 신청·키 발급이 선행돼야 합니다(앱 밖 절차).

[권장 전환 순서]

  1) LS에서 실거래 API 키 발급받기
  2) setup.exe --env prod  로 실거래 키·계좌비번 등록
  3) .env 에서 LS_ENV=prod + 계좌번호를 실계좌로
  4) setup.exe --check --env prod  로 등록 확인
  5) TrdBot.exe 실행 → 관찰모드로 로그 확인
     (토큰 발급 성공 / 실거래 계좌 조회되는지) → 이상 없으면 '주문' 체크

  가장 흔한 실수: ②(계좌번호 교체)를 빼먹는 것,
                  ③에서 --env prod 를 빼고 등록하는 것.


====================================================================
 다른 PC로 옮길 때 주의
====================================================================

  API 키·계좌비밀번호는 Windows 자격 증명 관리자(그 PC 전용)에
  저장되므로 폴더를 복사해도 따라오지 않습니다.
  새 PC에서는 setup.exe 를 다시 한 번 실행해 등록해야 합니다.
  (.env 의 계좌번호는 파일이라 복사하면 그대로 따라옵니다)
